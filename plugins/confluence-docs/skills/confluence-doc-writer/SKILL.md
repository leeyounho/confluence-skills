# Confluence 문서 작성

Claude와 Codex에서 사용하는 이식 가능한 문서 작성 스킬이다. 기본 전달 방식은 **브라우저에서 렌더링된 본문을 복사해 Confluence 편집기에 붙여넣기**다.

## 작업 방식

1. 사용자가 제공한 메모, 파일, 코드, 기존 문서에서 목적·독자·핵심 사실을 파악한다. 기존 문서 수정은 의도와 용어를 유지한다. 요청 언어를 따르고 별도 지정이 없으면 한국어로 쓴다.
2. 일반적인 구성 선택은 자율적으로 진행한다. 누락된 정보가 결론이나 절차의 정확성을 좌우할 때만 질문한다. 나머지는 `확인 필요` 또는 `가정`으로 구분한다. 담당자·일정·측정값·명령 실행 결과·출처를 만들어내지 않는다.
3. 사용자가 제공한 양식이 우선이다. 양식이 없으면 [문서별 구성](references/document-types.md)에서 요청에 맞는 부분만 선택한다. 모든 문서에 같은 목차를 강제하지 않는다.
4. [붙여넣기 출력 규칙](references/paste-format.md)을 읽고 제목, 요약, 본문을 작성한다. 짧은 설명은 짧게 유지하고 운영 문서는 실제 실행에 필요한 조건과 확인 방법을 포함한다.
5. 파일을 만들 수 있으면 같은 내용의 `<slug>.html`과 `<slug>.md`를 사용자 작업 폴더에 생성한다. HTML은 기본 전달물, Markdown은 수정용 원본이다. HTML 코드 블록을 보여주는 것만으로 파일 생성을 대신하지 않는다.
6. 제목 계층, 표, 링크, 코드와 원문의 사실 일치를 확인한다. 가능하면 HTML을 브라우저/미리보기로 열어 확인한다. 미리보기를 사용할 수 없으면 구조와 내용을 검토하고, 실제 Confluence 붙여넣기는 검증하지 않았음을 필요한 경우 짧게 알린다.
7. 최종 응답에는 파일 링크와 아래 사용법을 짧게 제공한다. 문서 내용에 설치 안내나 모델의 작업 설명을 섞지 않는다.

## 전달 계약

- HTML의 페이지 제목은 파일의 `<title>`과 문서 상단 `<h1>`에 넣는다. Confluence 제목 필드에 입력할 제목도 알려준다. 본문 복사 범위에서는 상단 제목을 제외해 중복을 방지한다.
- 사용법: `HTML 파일을 브라우저로 열기 → 제목 아래 본문을 선택해 복사 → Confluence 제목 입력 → 본문에 일반 붙여넣기 → 표·코드·링크 확인`.
- 서식을 보존하려면 **보이는 본문**을 복사해야 한다. HTML 소스나 Markdown 원문을 그대로 붙여넣으면 동일한 서식을 보장할 수 없다. 일반 붙여넣기를 사용하며, 서식 없는 붙여넣기는 피한다.
- 파일 생성이 불가능한 환경에서는 채팅에 렌더링된 문서를 제공하고 서식 보존이 환경에 따라 다름을 알린다. 파일을 만들었다고 주장하지 않는다.
- 이미지가 있으면 문서와 함께 이미지 파일 목록을 제공한다. 로컬 이미지가 붙여넣기로 Confluence에 첨부된다고 가정하지 않는다. 필요한 이미지 업로드/삽입 위치를 설명한다.
- Confluence Cloud/Data Center와 편집기 버전에 따라 붙여넣기 결과가 다를 수 있다. 대상 환경이 불명확하면 기본적인 제목·문단·목록·표 중심으로 만든다.

## 범위와 다른 출력 요청

이 스킬은 문서를 작성하는 데 집중한다. 문서 작성 요청만으로 Confluence에 접속하거나 페이지를 생성·게시·덮어쓰지 않는다. 사용자가 게시까지 명시적으로 요청했다면 사용 가능한 연결 도구와 해당 권한을 확인하고 진행한다.

사용자가 `.docx` 가져오기, API storage 형식 또는 레거시 wiki markup을 지정하면 해당 요청을 우선한다. 대상 제품·편집기에서 그 형식을 지원하는지 확인하고 적합한 도구를 사용한다. 일반 HTML을 Confluence storage 형식이라고 부르거나 `.md` 파일의 기본 가져오기를 보장하지 않는다. 레거시 매크로 문법은 기본 본문에 넣지 않는다.
