# HTML 소스 입력용 출력

## 본문 파일: 기본 산출물

`<slug>.body.html`을 UTF-8로 만든다. **`<body>` 내부의 내용만** 담으며 `<body>` 태그 자체도 제외한다. `DOCTYPE`, html/head/body/title/meta/style/script와 main 래퍼, Markdown 코드 펜스, 생성 안내를 넣지 않는다. 전체 소스를 바로 복사해 HTML 소스 입력 창에 넣을 수 있어야 한다.

```html
<p>문서의 목적과 핵심 내용을 요약한다.</p>
<h2>본문의 첫 번째 주제</h2>
<p>실제 문서 내용.</p>
```

예시 문구는 실제 내용으로 대체한다. 페이지 제목은 별도로 전달하며 본문에 h1으로 중복하지 않는다. 외부 라이브러리, JavaScript, 외부 폰트, head의 CSS에 의존하지 않는다. 기본은 의미 구조가 있는 태그이며, 사용자 환경에서 확인된 경우에만 최소한의 인라인 스타일을 사용한다. 지원 여부를 모르는 매크로 문법은 넣지 않는다.

## 미리보기 파일: 선택 산출물

브라우저 확인이 필요하면 `<slug>.preview.html`을 별도로 만든다. UTF-8 메타 태그와 title, 가독성을 위한 CSS, html/head/body를 포함할 수 있다. 본문 파일의 내용을 재사용하며 제목 h1은 미리보기에만 둘 수 있다. 로컬 그림의 상대 경로도 이 파일에서만 사용한다. 미리보기 전체 소스를 Confluence 입력 창에 넣도록 안내하지 않는다.

Markdown은 제목과 같은 본문·표·코드를 포함하며 편집용으로 제공한다. HTML 파일 대신 Markdown을 입력하도록 안내하지 않는다.

## 표현 선택

| 요소 | 권장 표현 | 주의점 |
| --- | --- | --- |
| 제목 | 본문은 h2, 하위 주제는 h3부터 | 굵은 문단으로 제목 계층을 대신하지 않는다. |
| 문단 | p, strong, em | 색상만으로 의미를 전달하지 않는다. |
| 목록 | ul/ol/li | 단계는 번호 목록, 병렬 항목은 글머리표. |
| 표 | table/thead/tbody/tr/th/td | 셀 병합·중첩 표를 피한다. 긴 절차·코드는 표 밖에 둔다. |
| 링크 | a href | 사용자 제공 링크나 실제 확인한 링크만 사용한다. |
| 코드 | pre/code, 짧은 토큰은 code | 코드의 줄바꿈과 들여쓰기를 보존한다. 언어는 바로 앞에 표시한다. |
| 주의/팁 | 제목 또는 굵은 레이블 + 문단 | Confluence 패널 매크로로 자동 변환된다고 주장하지 않는다. |
| 체크 항목 | 일반 목록의 완료/미완료 텍스트 | 네이티브 작업 항목이나 담당자 멘션으로 변환된다고 가정하지 않는다. |
| 다이어그램 | 설명 + 필요하면 이미지 파일 | Mermaid 원문 입력으로 다이어그램이 생긴다고 가정하지 않는다. |

- 텍스트 노드의 `&`, `<`, `>`와 속성 값의 따옴표를 이스케이프한다. 코드에도 동일하게 적용한다. 원본 코드를 실행 가능한 HTML로 삽입하지 않는다.
- `javascript:` 같은 실행 URL, 이벤트 핸들러 속성, HTML 폼, iframe을 넣지 않는다.
- `{toc}`, `{code}`, `h1.` 등 wiki markup과 `ac:` 매크로는 기본 본문에 넣지 않는다. 일반 HTML 조각은 API storage 형식이 아니다.
- 본문의 img src는 사용자가 제공하거나 확인한 Confluence 첨부 URL을 사용한다. URL이 없으면 생성한 그림의 위치를 `그림 삽입 위치: ...` 문단으로 표시하고 파일과 캡션을 전달한다. 로컬 경로, 임의 URL, 존재하지 않는 파일을 링크하지 않는다.
- 긴 문서의 목차는 간단한 텍스트로 작성하거나 Confluence 목차 요소 삽입을 별도로 안내한다. 앵커 지원을 보장하지 않는다.
- HTML 템플릿이 전체 문서여도 본문 부분만 추출하고 제목·작성용 주석·외곽 태그를 정리한다. 템플릿의 head/style을 본문 파일에 복사하지 않는다.

## 확인

Python이 있는 환경에서는 로컬 읽기 전용 [검사 도구](../scripts/validate_body.py)를 실행하고 오류를 수정한 뒤 전달한다. 네트워크와 추가 패키지는 필요하지 않다.

```text
python <스킬폴더>/scripts/validate_body.py <문서.body.html>
```

검사 항목은 외곽 태그·페이지 제목 h1·작성용 주석·남은 자리표시자·코드 펜스·태그 닫힘·로컬 이미지 경로와 실행 URL 등이다. pre/code 안의 자리표시자나 코드 펜스는 코드 예제로 취급한다. 생성 HTML은 닫는 태그를 명시하며, 기본 태그 집합 밖의 요소는 사용자 환경에서 검증한 별도 형식인지 수동 검토한다. 도구는 내용을 고치거나 파일을 덮어쓰지 않는다.

Python 실행을 지원하지 않는 환경은 아래 항목을 수동 검사하고 자동 검사를 실행했다고 주장하지 않는다. 런타임 설치를 강제하지 않는다. 도구 통과는 사실성, Markdown 내용 일치, 실제 Confluence 표시나 일반 HTML의 안전성을 보장하는 인증이 아니다.

본문 파일에 금지한 외곽 태그·코드 펜스·페이지 제목 중복·로컬 이미지 경로가 없는지 확인한다. 태그의 닫힘, 제목 계층, 이스케이프, UTF-8 인코딩과 HTML/Markdown 내용·표 셀·코드 일치를 검토한다. 미리보기에서는 파일별 제목 및 이미지 경로 차이만 허용한다.

실제 사용자 환경에 접근할 수 있으면 HTML 소스 입력 후 적용하고 표의 열, 코드 줄바꿈, 링크 대상을 확인한다. 브라우저 미리보기만 확인한 경우 회사 입력 기능을 검증했다고 주장하지 않는다. 검증을 위해 요청 없이 페이지를 게시하지 않는다.

## 다른 입력 방식

일반 편집기에 서식 복사를 명시한 경우에만 미리보기를 브라우저로 열어 보이는 본문을 일반 붙여넣기하도록 안내한다. HTML 소스를 일반 편집기에 넣는 방식과 구분한다.

HTML 소스 입력은 사용자의 회사 환경에서 확인한 방식을 기본으로 한다. 설치 앱·제품·편집기마다 지원 범위가 다르다. [Confluence Cloud 문서 가져오기 안내](https://support.atlassian.com/confluence-cloud/docs/import-content-into-confluence-cloud/)의 서식 있는 텍스트 붙여넣기는 별도 방식이며 모든 환경의 HTML 소스 입력을 보장하는 근거가 아니다.
